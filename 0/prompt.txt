**Core owns Assessment registration and immutable storage.**

- observes domain/graph context;
- constructs an Assessment candidate;
- initiates registration through the Core API.

- validates the candidate;
- enforces contextual validation where required;
- owns the registration operation;
- creates the immutable registered representation;
- controls admission into registered state.

Validation must be inseparable from admission into registered state.

No supported public API may allow an Assessment to enter registered state without mandatory Core validation.

1. Generic Assessment validation.

A shape-valid but semantically false C-1 Assessment must not be registerable through any supported public registration path.

There is currently no established production host adapter in the repository.

Do not describe this module as a production integration.

### DECISION D — Publication boundary

- event publisher;
